# 🔒 Безопасность

## Модель угроз

Бот даёт управлять Claude Code на твоей машине из Telegram. Claude выполняет команды **с правами пользователя, под которым запущен бот** (режим bypassPermissions, без подтверждений). Поэтому:

- бот обслуживает ровно одного человека — `TELEGRAM_OWNER_ID` — и только в личном чате. Сообщения других людей, групп и ботов отбрасываются до любых действий: скачивания, расшифровки, запуска Claude;
- кто получил доступ к твоему Telegram-аккаунту, тот получил доступ к машине. Включи в Telegram облачный пароль (Настройки → Конфиденциальность → Облачный пароль);
- не запускай бота от `root`, если можно завести обычного пользователя.

## Только подписка

- Бот не использует API Anthropic. Он не стартует, если в окружении есть `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN` или `CLAUDE_CODE_OAUTH_TOKEN`.
- Процесс Claude получает чистое окружение (без токена бота и ключа OpenAI) и авторизуется только входом `claude auth login`.
- Если Claude всё же сообщил, что запущен не по подписке (`apiKeySource` не `none`), бот сразу его останавливает.

## Секреты

- Токен бота и ключ OpenAI (только для голоса) хранятся в `.env` (права `600`, файл в `.gitignore`). Ключи my.telegram.org скрипт переносит в `~/.local/share/telegram-bot-api/api.env` (`600`).
- Бот вырезает известные ему секреты и всё, похожее на токены и ключи, из логов и сообщений.
- `.env*`, `~/.claude/.credentials.json`, `~/.claude/sessions`, SSH-ключи, данные Local Bot API и небольшие файлы, в которых встречается токен или ключ, бот в Telegram не отправляет, даже если Claude на них сослался.
- Входящие файлы — недоверенные данные: они сохраняются под сгенерированными именами в `~/.claude-telegram/files`.
- `npm run doctor` не печатает значения секретов.

## Если токен утёк

1. [@BotFather](https://t.me/BotFather) → `/revoke` (или в мини-приложении: бот → API Token → Revoke) → новый токен в `.env`. Если стоит Local Bot API, запусти `bash scripts/install-local-bot-api.sh` ещё раз.
2. Ключ OpenAI удали на [platform.openai.com/api-keys](https://platform.openai.com/api-keys) и создай новый.
3. Перезапусти бота. При подозрении на доступ к Claude — `claude auth logout` и `claude auth login`.

## Как сообщить об уязвимости

Не создавай публичный issue. Используй **Security → Report a vulnerability** в этом репозитории.
